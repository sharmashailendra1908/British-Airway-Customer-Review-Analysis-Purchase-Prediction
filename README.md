# British Airways Customer Booking Prediction ✈️

## 📌 Project Overview
This project analyzes airline customer data to understand the factors that influence booking behavior and predicts whether a customer will complete a booking.

The project was completed as part of a Data Science job simulation, demonstrating how machine learning can support business decision-making in the airline industry.

---

## 🎯 Objectives
- Analyze customer booking data
- Identify key factors influencing purchase decisions
- Build a predictive machine learning model
- Generate business insights from data

---

## 📊 Dataset Features
Key features used in the model include:

- purchase_lead — Days between booking and travel  
- flight_hour — Scheduled departure hour  
- length_of_stay — Duration of trip  
- num_passengers — Number of travelers  
- flight_duration — Flight time  

---

## 🧠 Methodology

### 1️⃣ Data Preprocessing
- Handling missing values
- Encoding categorical variables
- Feature selection

### 2️⃣ Exploratory Data Analysis (EDA)
- Distribution analysis
- Correlation analysis
- Visualization of key patterns

### 3️⃣ Model Building
- Machine learning classification model
- Feature importance analysis
- Model evaluation

---

## 📈 Results
The model identified booking lead time, flight timing, and trip duration as the most influential factors in predicting customer purchase behavior.
